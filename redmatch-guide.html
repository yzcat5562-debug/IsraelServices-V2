Red Match 2 — Setup Guide

1. Install Redmatch 2

  • Open Steam and install Redmatch 2 (free game)
  • Make sure it's in the default location:
    C:\Program Files (x86)\Steam\steamapps\common\Redmatch 2
  • Launch the game once to make sure it works, then close it

2. Install

  • Run start.bat (!AND BE SURE THAT THE DLL IS IN THE SAME FOLDER!)
  • Start Redmatch 2 from Steam normally
  • A window appears asking for a key

3. The Key

  • Enter the key that you got from the linkvertise
  • Click Authenticate

In-Game Controls

  • INSERT = Open/close menu
  • END = Unload the cheat completely
  • RMB = Aimbot (when enabled in menu)
